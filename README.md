# CoffeeOne

A responsive landing page for a specialty coffee shop in Monastir, Tunisia. Built with plain HTML, CSS and JavaScript, no framework needed.

## Features

- Hero section with a featured drink
- About, menu, "from bean to cup" process and shop sections
- Customer reviews and a blog section
- Search bar, cart panel and mobile menu
- Contact form and newsletter signup
- Responsive layout for phone, tablet and desktop

## Tech stack

HTML5, CSS3, JavaScript, Font Awesome, Google Fonts (Young Serif, Manrope)

## Getting started

No install needed. Download or clone the repo, then open `index.html` in your browser.

```
git clone https://github.com/Safwen-bm/coffee-shop.git
cd coffee-shop
```

## Project structure

```
index.html       page markup
styles/          style.css
js/              script.js
images/          photos, icons and favicon
```

## Notes

The contact and newsletter forms only show a thank-you message for now. Connect them to a backend or a service like Formspree to receive real messages.
